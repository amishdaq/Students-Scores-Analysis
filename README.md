# Student Performance Analysis

## Overview
An exploratory data analysis project examining which factors most strongly influence student exam performance, using a dataset of 6,607 students from Kaggle.

## Tools Used
- Power Query (data cleaning)
- Power BI (visualization & Key Influencers analysis)

## Process
1. Data cleaning (missing values, duplicates, outliers, standardization)
2. Exploratory Data Analysis (EDA)
3. Statistical analysis using Power BI's Key Influencers visual

## Key Findings
- **Hours Studied** is the strongest predictor of exam performance
- **Parental Involvement** is the second most influential factor
- **Attendance** shows a moderate positive relationship
- Sleep hours, gender, internet access, and teacher quality showed minimal impact
